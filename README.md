# Favorite Movies Website

A simple multi-page HTML website showcasing my 5 favorite movies.

## Live Demo
https://nitinfavmovies.netlify.app

## Pages
- Home: `index.html`
- F1: `f1.html`
- Batman Begins: `batman.html`
- Top Gun: Maverick: `topg.html`
- Avengers: Endgame: `avengers.html`
- The Shawshank Redemption: `shawshank.html`

## Features
- Movie name links to dedicated pages
- Ratings for each movie
- Poster image for each movie
- Synopsis and cast list for every movie page

## Tech Used
- HTML5
- Basic CSS
- Netlify (deployment)
